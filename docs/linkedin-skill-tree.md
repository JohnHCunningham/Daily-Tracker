# LinkedIn Skill Tree — Finley Topping

6 Claude skills in sequence for LinkedIn outreach. Source: Finley Topping.

## The Six Skills

1. **ICP Decoder** — define ideal buyer (job titles, pain points, scroll triggers)
2. **Profile Architect** — profile as infrastructure, not CV (headline, about, trust signals)
3. **Hook Engineer** — opening lines that interrupt patterns (re-engagement, authenticity)
4. **Carousel Composer** — carousels for dwell time (structure, narrative arc, CTAs)
5. **DM Sequencer** — conversations that lead to calls (context, validation, no templates)
6. **Lead Scorer** — focus on leads most likely to buy (fit, intent, next best action)
